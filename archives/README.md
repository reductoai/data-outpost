# Local archives

This folder consolidates the source material behind every Unlisted Project listing.

- `curated-index.json` summarizes the 36-PDF cross-property pack.
- Every property has a `manifest.json` with source URLs, sizes, pages, and checksums.
- `haas-lilienthal/full-sf-1906-archive/` contains the complete 194-file, roughly 520 MB San Francisco workshop collection, including its own CSV and JSON manifests.
- `linked_collections` entries identify institutional holdings that are available only item-by-item or by reading-room consultation.

The curated pack totals **5,378 pages and 357.5 MB** before the complete Haas/San Francisco collection is counted.

See [`../docs/RIGHTS_AND_ACCESS.md`](../docs/RIGHTS_AND_ACCESS.md) before publishing or redistributing archival content.
